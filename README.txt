RAMIKA BRO TECH — WEBSITE
=========================

CONTACT FORM STORAGE
The contact form is configured for Netlify Forms. When this site is deployed to Netlify, submissions are saved to your Netlify site dashboard so you can review them later.

HOW TO VIEW SUBMISSIONS
1. Create/sign in to a Netlify account.
2. Deploy the contents of this ZIP (extract it first) as a static site on Netlify.
3. In the Netlify site dashboard, open Forms and confirm form detection is enabled if prompted.
4. Submit a test message from the live website.
5. Return to the site's Forms area to view submissions. You can also configure email notifications there.

IMPORTANT
- The form will NOT save visitor submissions when you just open index.html on your computer or host the files on a service that does not support Netlify Forms.
- This setup does not store submissions in the visitor's browser; it stores them with Netlify after deployment.
- Add your real YouTube channel link separately if you want a Subscribe button.
- The supplied logo is included unchanged in assets/logo.jfif.
